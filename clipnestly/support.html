Save a screenshot

Open the screenshot preview and tap Share, then ClipNestly. If it is missing, open More in the share-app row and enable it. Apple controls the screenshot editor’s Save menu; ClipNestly appears in the share sheet.

Clipboard permission

Tap Save or Paste to read the current clipboard. Auto-save is optional and runs only when ClipNestly opens or returns to the foreground. If iOS denies paste access, use the system Paste control or review the app’s paste permission in iPhone Settings.

Find a deleted item

Open ClipNestly Folders → Recently Deleted. Restore brings the item back; permanent deletion removes the local library copy. Your Photos original remains unchanged.

Backup and storage

Settings shows library size, manual export dates and iCloud backup status. Optional iCloud Drive backup updates a file while the app is open. Find it in iCloud Drive → ClipNestly → Backups; turning backup off keeps the existing file. Restore from Backup can open that file. This does not sync your working library. Export supports up to 150 MB of image data. Backups include Recently Deleted and are not encrypted by the app. Restore merges new items; it keeps existing items and your current settings.
