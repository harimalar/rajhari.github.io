Report a problem

Include your app version, macOS version, steps to reproduce, and what you expected. Use sample content; do not send passwords or sensitive screenshots. Ordinary bug reports may also be filed in GitHub Issues with “ScreenNestly” in the title. GitHub issues are public.

Common questions

A filed capture still appears in All Captures? All Captures includes project items. Inbox contains only unfiled captures.

Sharing after editing? Use Copy or Drag Image in the editor header. The canvas remains available for drawing.

Scrolling capture pauses? Select below fixed toolbars, keep the target uncovered, and scroll slowly with overlap. Watch the section counter. Auto-Scroll requires optional Accessibility access.

Does Save Backup include screenshots? No. It exports organization rules and settings only. Back up images and project folders separately.
